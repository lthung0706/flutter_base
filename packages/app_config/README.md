This package contains essential configs for the app to operate

## Features
- Provide configs for API from env file
- Provide constance configs for in-app usage

## Getting started
- whenever .env files are ```edited```, run the ```generate_app_config.sh``` file in the script folder
- only edit the file under the ```CONFIGS AFTER THIS LINE CAN BE MODIFIED MANUALLY``` line, everything above this line can be replaced by generated code from the script
